DURABLE AGENT HARNESS · EXPERIMENTAL
2.1.1

INTRODUCTION.

The pi-durable harness commits transcript entries and task decisions before publication. Checkpoints recover unfinished work; they do not make external effects exactly once (figure 2.1-1).

2.1.2

FUNCTIONAL DESCRIPTION.

A storage commit records entries, documents and task state together. Reopen changes running tasks to pending at their saved checkpoint; resume() enables scheduling. A tool intent is stored before execution. Recovery reruns it only when both stored and current replay policies are safe (figure 2.1-2).

2.1.2.1

Deferred Progress.

Watches see live partials and tool output before persistence. Storage follows at a phase boundary or the deferred interval; a crash can lose recent progress.
